# GitHub publishing steps

1. Create a GitHub account (or use your existing one) with a professional username.
2. Create a **public** repository named `okta-saml-sso-integration`.
3. Upload `README.md` and `troubleshooting.md` from this starter folder.
4. Do not label the lab complete until you perform the steps and record real test results.
5. Add sanitized screenshots and an architecture diagram only after reviewing for secrets and employer information.
6. Pin the repository on your GitHub profile; add the URL to your resume and LinkedIn.
7. Add a profile README later and link your SCIM, Workflows, and Entra labs as they are finished.
